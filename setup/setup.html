👋 Bienvenue dans MuslimGuard

Cette extension va vous aider à protéger votre famille des contenus inappropriés sur Internet tout en respectant les valeurs islamiques.

Fonctionnalités principales :

  • Blocage intelligent de sites et contenus inappropriés
  • Pause automatique pendant les heures de prière
  • Contrôle parental sécurisé avec code PIN
  • Monitoring et statistiques détaillées

🔒 Créez votre code PIN parental

Ce code vous permettra de gérer les paramètres de l'extension. Gardez-le secret et ne le partagez pas !

🛡️ Choisissez votre mode de protection

Sélectionnez le niveau de protection adapté à votre famille. Vous pourrez le modifier plus tard.

🕌 Configurez les horaires de prière

Internet sera en pause pendant ±15 minutes autour de chaque prière. Les sites islamiques restent accessibles.

✓

Configuration terminée !

MuslimGuard est maintenant actif et protège votre navigation. MashAllah !

Prochaines étapes :

  • Personnalisez les listes de blocage dans les Paramètres
  • Consultez le Dashboard parent pour voir les statistiques
  • Utilisez votre code PIN pour modifier les paramètres
